# Governanca e Aprovacoes

## Estado

Este documento define os papeis e gates necessarios. Os nomes dos responsaveis ainda nao foram
fornecidos e, portanto, nenhum piloto hospitalar ou uso clinico esta aprovado.

| Papel | Responsavel | Estado |
| --- | --- | --- |
| Patrocinador tecnico | PENDENTE DE INDICACAO | bloqueado |
| Especialista clinico | PENDENTE DE INDICACAO | bloqueado |
| Responsavel por privacidade | PENDENTE DE INDICACAO | bloqueado |

## Gates obrigatorios

1. O patrocinador tecnico aprova escopo, recursos, risco operacional e rollback.
2. O especialista clinico aprova classes, protocolo de anotacao, casos de abstencao e criterio de
   revisao humana.
3. O responsavel por privacidade aprova desidentificacao, acesso, retencao, logs e uso de dados.
4. As aprovacoes devem ser registradas com nome, funcao, data, versao do SDD e decisao.

Enquanto qualquer papel estiver pendente, o sistema permanece uma prova tecnica sem autorizacao
para dados hospitalares ou decisao clinica autonoma.
